# Known limitations

- PDF export uses the browser print dialog.
- Broker APIs, automated trade import and AI coaching belong to later phases.
- Automated browser end-to-end tests are not included because the current project has no established Playwright/Cypress setup.
- Production monitoring must be configured separately in Vercel/Supabase or a selected monitoring service.
- JSON backup is available, but a self-service restore UI is not included.
