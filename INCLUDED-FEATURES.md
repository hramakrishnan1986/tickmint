# TickMint V1 — Included Features

This combined codebase includes Milestones 1, 2A, 2B, 3A, 3B, 3C and 3D.

- Public landing page and responsive SaaS navigation
- Demo mode and Supabase email/password authentication foundation
- User profiles, sessions, logout and password reset foundation
- Dashboard with capital, P&L, win rate, profit factor and discipline
- Bull/Long and Bear/Short trading identity
- Trade journal with add, edit and delete
- Equity, futures, options, commodities, crypto and forex fields
- CE/PE, strike and expiry inputs
- Lots, lot size, quantity, stop loss, target and risk data
- Brokerage, exchange charges, taxes, slippage, gross and net P&L
- Screenshot upload foundation through Supabase Storage
- Search, filtering and CSV export
- Multiple trading accounts
- Capital deposits, withdrawals, fees, dividends and adjustments
- Equity curve, drawdown and advanced analytics
- Instrument, strategy, day, direction and psychology analytics
- Expectancy, payoff, drawdown, recovery, Sharpe and Sortino estimates
- Daily review and discipline workflow
- Trading calendar and review completion
- Expiry calendar guidance
- Daily, weekly and monthly reports
- Achievements and habit tracking
- Feedback and support centre
- Settings and analytics consent
- Privacy, terms, risk disclaimers, custom 404 and error recovery
- Supabase SQL schema with Row Level Security
- Vercel deployment instructions and QA checklist
